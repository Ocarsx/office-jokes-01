One-line office joke for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty. `main.ts` (Node 22) deterministically writes a single 100-character office joke to `/output/entry.txt` — nothing else.

> I told my boss I work best under pressure, so now he schedules all my deadlines for the same Friday.

## Run it

```sh
node main.ts
```

The grader runs it as `node /bot/main.ts` with `/output` mounted writable; locally, set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written.
